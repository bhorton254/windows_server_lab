# windows_server_lab
My VirtualBox home lab which simulates a small enterprise environment which currently consists of 10 users. This home lab demonstrates identity and network management primarily using Active Directory on Windows Server 2025. 


--------------------------------------------------------

(**Overview**)

This repository documents my ongoing, hands-on experience with IT infrastructure, systems administration, networking, and virtualization.

The purpose of this home lab is to develop the practical skills in deploying, configuring, managing, and troubleshooting enterprise-style IT environments. Using VirtualBox VMs and various networking tools, I aim to simulate common administrative tasks and explore how different infrastructure components interact.

Each project will be organized into its own directory containing configuration notes, network diagrams, screenshots, implementation steps, and troubleshooting documentation.

(**Technologies & Tools**)

- Oracle VirtualBox
- Windows Server 2025
- Windows 11
- Active Directory Domain Services (AD DS)
- Windows networking and command-line utilities (i.e., ping, ipconfig)

(**Planned Areas of Exploration**)

- Group Policy Management
- DNS and DHCP administration (including troubleshooting)
- Virtual LANs (VLANs) and network segmentation
- PowerShell scripting and automation
- Exploring infrastructure security
